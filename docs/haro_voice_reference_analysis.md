# ハロ参考動画の音声・動作解析と再現仕様

## 対象資料

利用者提供の録画 `ScreenRecording_11-18-2026 16-14-50_1.mp4`（2026-11-18）。
実測値はこの **約2.03秒の動画の混合音声トラック**に由来します。映像中の字幕には「ライフルビット展開！」の反復が確認できます。

| 観測項目 | 解析結果 |
|---|---|
| コンテナ | MP4 |
| 音声 | AAC-LC 44,100Hz / 2ch |
| 録画時間 | 約2.03秒 |
| モノラル変換後の波形RMS | 約0.086（線形0〜1スケール） |
| モノラル変換後の波形ピーク | 約0.539（同上） |
| 有声音に見える区間のピッチ候補 | 約420〜500Hzの帯域も観測 |
| スペクトル重心の目安 | 多くの区間で約2〜3.2kHz |

**重要:** 録画にはゲームのBGM、効果音、複数話者が混在しています。
上述のピッチ・RMS・スペクトル数値は声だけを抽出した数値ではありません。
特定キャラクターの声の基本周波数や声優音声の特徴量として断定しません。
音源から人の声をクローンする処理は実装していません。

## 聴感・映像の特徴（画面から読み取れる範囲）

- 短いフレーズを切れよく反復する、甲高めで機械的な印象の発声
- 発話の区間で両目が発光して暗転・点灯を繰り返す
- 左右の耳がハッチのように開き、内部の駆動部が見える
- 左右の耳は完全同時ではなく少し位相をずらして開閉する
- 頭部全体がわずかに傾く

## Webブラウザでの近似再現

1. **声**: 日本語Web Speech API `SpeechSynthesisUtterance`、標準ピッチ `1.50`、話速 `1.25`。画面のスライダーで変更可。設定をブラウザ内に保存
2. **個体差**: LOGOS（オレンジ）を基準とし、CHAOS（青）は少し低め、NEMESIS（緑）は少し高め
3. **電子音**: Web Audio APIの三角波で短い2音チャープを合成。ゲーム音源は転載せず完全にオリジナルの音を生成。音声と別トラックとして重ねる
4. **口調**: 短い文節・句読点・明瞭な繰り返しなどの表現を利用
5. **耳**: SVGの左右開閉ハッチを独立回転。開くと内部歯車／駆動軸が見える
6. **目**: 発話中に発光・点滅。音声イベントでアニメ速度を変える
7. **頭部**: 発話中に小さく左右へ傾ける
8. **同期**: `onstart`／`onboundary`／`onend`でアニメを制御。境界イベントのないブラウザでは約200ms前後の代替リズムを使う

## 再現の限界

- ブラウザ標準TTSの声質はOS・端末・インストールされた音声によって異なる
- 音声合成のPCMサンプルをWeb Audioへ直接取り出せないため、音声そのものへリングモジュレーションやフォルマント変換は行っていない
- 目・耳の連動は**音声波形の振幅ではなく、発話時間と語句境界を使った近似同期**
- iPhoneの音声認識はHTTPSまたはブラウザ制約があり、ローカルLANのHTTP環境ではマイク起動できない場合がある
- 原作の音声ファイル・効果音・楽曲は一切同梱しない

## 調整方法

起動後の `HARO VOICE LINK` パネルで「声の高さ」「話す速さ」「電子音アクセント」を調整し、「試聴」を押す。
高すぎて不自然ならピッチを1.25〜1.40、速すぎるなら話速を1.05〜1.15にする。
録音とOSの音声合成の品質は異なるため、**発表で使用するPCの実際のスピーカーで最終調整すること**。
